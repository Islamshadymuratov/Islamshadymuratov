GREEN-API · WHATSAPP HTTP API

Тестовая консоль методов инстанса

Укажите параметры подключения к инстансу и вызовите методы getSettings, getStateInstance, sendMessage и sendFileByUrl напрямую из браузера. Ответ каждого метода выводится в поле только для чтения ниже.

Подключение к инстансу

idInstance и ApiTokenInstance берутся из личного кабинета GREEN-API. Они используются во всех запросах ниже и сохраняются только в этом браузере.

параметры не сохранены

getSettings

Возвращает текущие настройки инстанса.

ОТВЕТ

getStateInstance

Возвращает статус авторизации инстанса (authorized, notAuthorized, blocked и т.д.).

ОТВЕТ

sendMessage

Отправляет текстовое сообщение на указанный номер WhatsApp.

ОТВЕТ

sendFileByUrl

Отправляет файл по прямой ссылке на указанный номер WhatsApp.
